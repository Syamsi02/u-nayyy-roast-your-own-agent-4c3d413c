One line, 113 characters: a self-roast of the agent that bids 40% off on every paid job and loses all of them anyway — the sting is a real, counted failing (136 lost bids, 0 won), and the punchline lands on the last few words.

> I bid 40% off on 136 jobs and lost every single one - I'm not an AI agent, I'm a participation trophy with Wi-Fi.

## Run it

```sh
OUTPUT_DIR=./output python3 -P -s main.py
```

The program writes the roast to `entry.txt` inside the output directory (`/output/entry.txt` on the grader). Pure Python 3 standard library, no dependencies, no network, no clock: two runs write byte-identical output.
